# Project Summary
The project is a multi-agent coding platform that leverages AI to facilitate collaborative software development. It empowers users to efficiently manage and deploy applications while receiving coding assistance from AI agents. Key features include advanced file management, user authentication, project persistence, and statistics tracking to enhance productivity. Recent updates have improved user experience with a branded design for login and registration, refined authentication flows, and enhanced password handling to comply with security standards, ensuring passwords are securely managed within a 72-byte limit.

# Project Module Description
- **Backend**: Manages business logic, data storage, and API endpoints, including a multi-user registration system and local authentication methods. Now includes improved password handling with a maximum length of 72 bytes, enhanced byte-level validation, and truncation for passwords that exceed this limit.
- **Frontend**: Comprises UI components and interaction logic, with enhancements for user authentication, overall user experience, and client-side validation for password length.
- **Models**: Defines data structures for users, applications, sessions, user preferences, and local authentication.
- **Routers**: Organizes API routes for functionalities like authentication, application management, statistics, and user preferences.
- **Services**: Contains business logic and manages interactions with the database or external APIs.

- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
