# Project Summary
The project is a multi-agent coding platform utilizing AI to enhance collaborative software development. It allows users to efficiently manage applications, deploy them, and receive coding assistance through AI agents. The platform features robust file management, user authentication, project persistence, and statistics tracking, all within a user-friendly interface designed to boost productivity. Recent updates have focused on improving theme and editor configurations, as well as resolving issues related to user preferences.

# Project Module Description
- **Backend**: Manages business logic, data storage, and API endpoints. Recent improvements include enhanced user preferences and API key management.
- **Frontend**: Comprises user interface components and interaction logic, with updates to support user preferences and enhance the settings experience.
- **Models**: Defines data structures for users, applications, sessions, user preferences, and API keys.
- **Routers**: Organizes API routes for functionalities like authentication, application management, statistics, user preferences, and API keys.
- **Services**: Contains business logic and manages interactions with the database or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
