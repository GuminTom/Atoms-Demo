# Project Summary
The project is a multi-agent coding platform that leverages AI to facilitate collaborative software development. It empowers users to manage applications efficiently, deploy them, and receive coding assistance from AI agents. The platform incorporates advanced file management, user authentication, project persistence, and statistics tracking, all designed to enhance productivity. Recent updates have introduced a multi-user registration system, allowing users to register and log in using usernames and passwords.

# Project Module Description
- **Backend**: Handles business logic, data storage, and API endpoints. Recent enhancements include a multi-user registration system and local authentication methods.
- **Frontend**: Comprises UI components and interaction logic, with updates to support user authentication and enhance user experience.
- **Models**: Defines data structures for users, applications, sessions, user preferences, and local authentication.
- **Routers**: Organizes API routes for functionalities like authentication, application management, statistics, and user preferences.
- **Services**: Contains business logic and manages interactions with the database or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
