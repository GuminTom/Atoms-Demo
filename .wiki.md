# Project Summary
The project is a multi-agent coding platform that utilizes AI to enhance collaborative software development. It enables users to efficiently manage and deploy applications while receiving coding assistance from AI agents. Key features include advanced file management, user authentication, project persistence, and statistics tracking, all designed to boost productivity. Recent updates have focused on improving user experience with a refined design for login and registration, optimized authentication flows, and enhanced password handling for better security compliance.

# Project Module Description
- **Backend**: Handles business logic, data storage, and API endpoints, including user registration and local authentication. Enhanced password handling now enforces a maximum length of 72 bytes with improved validation.
- **Frontend**: Comprises UI components and interaction logic, with enhancements for user authentication and client-side password validation.
- **Models**: Defines data structures for users, applications, sessions, and preferences.
- **Routers**: Organizes API routes for authentication, application management, and user preferences.
- **Services**: Contains business logic and manages interactions with databases or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
