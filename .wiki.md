# Project Summary
The project is a multi-agent coding platform that utilizes AI to enhance collaborative software development. It provides tools for efficient application management and deployment, along with real-time coding assistance. Key features include advanced file management, user authentication, project persistence, and statistics tracking, all aimed at boosting developer productivity. Recent updates have focused on improving the user experience and resolving issues related to application creation and management for new users.

# Project Module Description
- **Backend**: Manages business logic, data storage, and API endpoints, including user registration and local authentication with enhanced password security.
- **Frontend**: Contains UI components and interaction logic, with updates to user authentication, client-side validation, and navigation features. The "Project Type" functionality has been removed for a streamlined user interface.
- **Models**: Defines data structures for users, applications, sessions, and preferences.
- **Routers**: Organizes API routes for authentication, application management, and user preferences, now including updates for SSE streaming.
- **Services**: Implements business logic and manages interactions with databases or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
