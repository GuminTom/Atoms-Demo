# Project Summary
The project is a multi-agent coding platform that integrates AI capabilities for collaborative software development. It enables users to manage applications, deploy them, and interact with AI agents for coding assistance. Key features include file management, user authentication, project persistence, and statistics tracking, all designed to enhance productivity and streamline the development process.

# Project Module Description
- **Backend**: Manages business logic, data storage, and API endpoints.
- **Frontend**: Delivers user interface components and interaction logic.
- **Models**: Defines data structures for various entities such as users, apps, and sessions.
- **Routers**: Handles API routes for functionalities including authentication, app management, and statistics.
- **Services**: Contains business logic and interactions with the database or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
