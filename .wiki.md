# Project Summary
The project is a multi-agent coding platform that leverages AI to facilitate collaborative software development. It enables users to efficiently manage and deploy applications while receiving real-time coding assistance. The platform includes features for advanced file management, user authentication, project persistence, and statistics tracking, all designed to enhance developer productivity. Recent updates have improved the user experience and addressed issues with app creation and management, particularly for newly registered users.

# Project Module Description
- **Backend**: Handles business logic, data storage, and API endpoints, including user registration and local authentication with enhanced password security.
- **Frontend**: Comprises UI components and interaction logic, with updates to user authentication, improved client-side validation, and navigation features. The "Project Type" functionality has been removed for a cleaner user interface.
- **Models**: Defines data structures for users, applications, sessions, and preferences.
- **Routers**: Organizes API routes for authentication, application management, and user preferences.
- **Services**: Contains business logic and manages interactions with databases or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
