# Project Summary
The project is a multi-agent coding platform that leverages AI capabilities to facilitate collaborative software development. It empowers users to manage applications, deploy them, and receive coding assistance from AI agents. Key features include file management, user authentication, project persistence, statistics tracking, and a user-friendly interface aimed at enhancing productivity. Recent updates have improved user preferences management, enabling dynamic settings such as theme and editor configurations, and addressing issues with saving preferences.

# Project Module Description
- **Backend**: Handles business logic, data storage, and API endpoints, with recent enhancements to user preferences and API key management.
- **Frontend**: Provides user interface components and interaction logic, with updates to support user preferences and improve the settings experience.
- **Models**: Defines data structures for various entities, including users, applications, sessions, user preferences, and API keys.
- **Routers**: Manages API routes for functionalities such as authentication, application management, statistics, user preferences, and API keys.
- **Services**: Contains business logic and interactions with the database or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
