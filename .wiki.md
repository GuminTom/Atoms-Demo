# Project Summary
The project is a multi-agent coding platform that leverages AI to facilitate collaborative software development, empowering users to manage and deploy applications efficiently while receiving real-time coding assistance. Key features include advanced file management, user authentication, project persistence, and statistics tracking, all aimed at enhancing developer productivity. Recent updates have focused on improving user experience in the workspace interface.

# Project Module Description
- **Backend**: Manages business logic, data storage, and API endpoints, including user registration and local authentication. Password handling has been enhanced for security and validation.
- **Frontend**: Comprises UI components and interaction logic, with updates to user authentication and improved client-side validation.
- **Models**: Defines data structures for users, applications, sessions, and preferences.
- **Routers**: Organizes API routes for authentication, application management, and user preferences.
- **Services**: Contains business logic and manages interactions with databases or external APIs.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, Passlib
- **Frontend**: TypeScript, React, Vite, Tailwind CSS
- **Database**: PostgreSQL
- **Deployment**: Docker, AWS Lambda

# Usage
To get started with the project:
1. **Install Dependencies**:
   - For the backend, run:
     ```
     pip install -r app/backend/requirements.txt
     ```
   - For the frontend, run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python app/backend/main.py
     ```
   - For the frontend, build the project using:
     ```
     pnpm run build
     ```

3. **Run the Project**:
   - Ensure the backend is running, then start the frontend with:
     ```
     pnpm run dev
     ```
