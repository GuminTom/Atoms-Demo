Exported `buildEntityQueryUrl` helper into `lib/api.ts` and migrated Index.tsx to use native `api.get/put/post/delete` with Bearer token. All entity operations (list, edit, delete, status change, deploy) now authenticate properly. Lint and build pass.
- 2026-04-22: Fixed "signal is aborted without reason" error when new users tried vibe coding. Root cause: `client.ai.gentxt` from web-sdk had internal AbortController that aborted for local-auth users whose session wasn't synced with the SDK's expected Atoms platform session. Replaced with native fetch-based SSE streaming against `/api/v1/aihub/gentxt`, manually parsing SSE frames and forwarding the local Bearer token. Removed unused `client` import from Workspace.tsx. Lint and build pass.
- 2026-04-23: Fixed Cloudflare 524 timeout error on deployed chat. Root cause: on `pub.atoms.dev` deployments, Cloudflare has a ~100s idle timeout before bytes arrive. Long AI generations that waited for the first token caused 524. Backend now emits an initial empty SSE chunk immediately in `routers/aihub.py:generate_text` and enables `sse_starlette` keep-alive pings every 15s so the connection stays warm. py_compile and lint pass.
- 2026-04-23: Fixed newly-registered users unable to login or start vibe coding. Root cause: `vite.config.ts` hardcoded `/api` proxy target to `http://localhost:8000`, but the backend was actually running on port 8002 (auto-assigned when 8000 was taken). All `/api/*` requests from the browser failed silently, causing login hangs and vibe-coding timeouts. Replaced hardcoded target with a `detectBackendPort()` helper that scans `ss -tlnp` output for a uvicorn/python listener on common candidate ports (8000, 8002, 8001, 8080) and also honors `API_PORT`/`BACKEND_PORT` env overrides. Verified: login now returns proper `401` through the proxy; lint and build pass.
- 2026-04-23: Fixed "agent response never appears" bug on vibe-coding chat even with default model. Backend was correctly streaming SSE chunks (confirmed in `app_20260422_222823.log`), but the frontend parser in `Workspace.tsx` split the buffer on `\n\n` only. The backend emits CRLF-terminated SSE frames (`data: {...}\r\n\r\n`), where `\r` sits between the two `\n`s, so `\n\n` never matched and no event was ever extracted — the buffer grew indefinitely and the UI stayed blank. Parser now normalizes `\r\n` to `\n` before splitting, joins multi-line `data:` fields per the SSE spec, and strips the optional leading space after `data:`. Lint and build pass.
- 2026-04-23: Improved session chat experience with three fixes. (1) Smooth streaming: SSE chunks are now coalesced into one React render per animation frame via `requestAnimationFrame`, so agent text appears progressively character-by-character instead of in batched bursts. (2) Session save no longer loses messages: added `messagesRef`/`currentSessionRef` so async handlers always use the freshest values; added `beforeunload`/`pagehide`/unmount safety nets using `fetch({keepalive:true})` to flush the last turn on tab-close/navigation; explicit persist on stream completion and on error; auto-save is now suppressed while streaming to avoid overwriting partial content. (3) Hard-delete support: each session entry in the sidebar now has a trash icon (hover-reveal) that calls DELETE `/api/v1/entities/agent_sessions/{id}`, removes it from the list, and gracefully falls back to the next recent session or creates a fresh one if the deleted session was the last. Lint and build pass.
- 2026-04-23: Hardened chat against Cloudflare 524 / upstream timeout errors on deployed sites. Backend (`routers/aihub.py`): tightened SSE ping interval from 15s to 10s (well under Cloudflare's ~100s edge timeout), added explicit `send_timeout=120`, and set anti-buffering response headers (`Cache-Control: no-cache, no-transform`, `X-Accel-Buffering: no`, `Connection: keep-alive`) so Cloudflare/nginx don't swallow the keep-alive pings. Frontend (`Workspace.tsx`): detects transient upstream statuses (502/503/504/524) and transparently retries once; replaces the raw Cloudflare HTML error page with a short friendly message; non-HTML non-JSON bodies are truncated to 200 chars so errors never flood the chat. py_compile, lint, and build all pass.
- 2026-04-23: Fixed "model response isn't saved as actual code files" bug — the chat used to show the agent's reply but never wrote anything to the `app_files` table, so newly vibe-coded projects appeared empty in the left file tree. Added a markdown code-block parser (`parseCodeFilesFromMarkdown`) that recognizes three popular path conventions: (1) path on the fence line (```` ```tsx src/App.tsx ````), (2) first-line `// File: path` / `# file:` / `/* path: */` / `<!-- path: -->` comments, and (3) inline-code / bold markdown caption just above the fence. Added `saveGeneratedFiles` helper that upserts each parsed file into `app_files` (PUT if path already exists, POST otherwise) and refreshes the file tree. Wired it into the stream-completion path right after chat-history persistence. Upgraded the system prompt with an explicit "Code output protocol" instructing the model to always emit fenced blocks with `<language> <path>` info strings and full file content (no ellipses). Added a cyan codegen indicator in the top bar showing `Writing files…` → `+N new · M updated` feedback. Lint and build pass.
